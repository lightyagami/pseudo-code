# pseudoc

It can either execute pseudocode scripts directly on a stack-based virtual machine or translate them into standalone, readable C99 source code.

## Features

- **Execution Backends**:
  - Direct execution via an internal bytecode compiler and stack VM.
  - Native code emission by transpiling to C99 (`gcc`/`clang` compatible).
  - Interactive REPL with expression evaluation and multiline block auto-continuation.
- **Language Support**:
  - **Primitive Types**: `INTEGER`, `REAL`, `BOOLEAN`, `STRING`.
  - **Composite Types**: 1D and 2D `ARRAY` with arbitrary lower/upper bounds, and user-defined `TYPE ... ENDTYPE` records.
  - **Subroutines**: `PROCEDURE` and `FUNCTION`, recursion, return values, and explicit parameter passing (`BYVAL` default, `BYREF` mutable references).
  - **Control Flow**: `IF ... THEN ... ELSE ... ENDIF`, `WHILE ... DO ... ENDWHILE`, `FOR ... TO ... STEP ... NEXT`, and `CASE OF ... OTHERWISE ... ENDCASE`.
  - **File I/O**: `OPENFILE ... FOR READ|WRITE|APPEND`, `READFILE`, `WRITEFILE`, `CLOSEFILE`, and `EOF(...)`.
  - **Built-in Functions**: `LENGTH`, `SUBSTRING`, `UCASE`, `LCASE`, `NUM_TO_STR`, `STR_TO_NUM`, string concatenation (`&`), and integer arithmetic operators (`DIV`, `MOD`).
  - **Safety**: 64-bit integer overflow checks, runtime array bounds checking, and file handle tracking.

## Building

Requires a C++17 compiler (`g++` >= 8 or `clang++` >= 7) and `make`. No external libraries or tools needed.

```bash
make
```

Run test suite:

```bash
make test
```

Clean build artifacts:

```bash
make clean
```

## Usage

```text
usage: pseudoc [<input.pseudo>] [options]

Options:
  -o <output.c>         Compile pseudocode to C and write to <output.c>
  -c, --emit-c          Compile pseudocode and emit C source code to stdout
  -d, --dump-bc         Disassemble and inspect bytecode without executing
  -i, --repl            Run interactive REPL
  -h, --help            Show help message

Default behavior:
  pseudoc script.pseudo Execute script directly on the Pseudoc VM
  pseudoc               Start interactive REPL
```

### Examples

**1. Run on VM directly:**
```bash
./pseudoc tour.pseudo
```

**2. Transpile to C and build a binary:**
```bash
./pseudoc tour.pseudo -o tour.c
gcc -O2 tour.c -o tour
./tour
```

**3. Inspect generated bytecode:**
```bash
./pseudoc tour.pseudo -d
```

**4. Interactive REPL:**
```text
$ ./pseudoc
Pseudoc REPL v3.0 (VM-powered, type ':q' or 'EXIT' to quit)
>>> DECLARE x : INTEGER
>>> x <- 42
>>> x * 2
84
>>> :q
```

## Language Reference

### Variables & Records
```text
TYPE Student
    DECLARE name : STRING
    DECLARE score : INTEGER
ENDTYPE

DECLARE s1 : Student
DECLARE s2 : Student

s1.name <- "Alice"
s1.score <- 95

// Value assignment creates a copy
s2 <- s1
s2.score <- 100

OUTPUT s1.name, " scored ", s1.score
OUTPUT s2.name, " scored ", s2.score
```

### Arrays
```text
DECLARE grid : ARRAY[1:3, 1:3] OF INTEGER
DECLARE r : INTEGER
DECLARE c : INTEGER

FOR r <- 1 TO 3
    FOR c <- 1 TO 3
        grid[r, c] <- r * c
    NEXT c
NEXT r
```

### Procedures & Functions
```text
PROCEDURE Swap(BYREF a : INTEGER, BYREF b : INTEGER)
    DECLARE temp : INTEGER
    temp <- a
    a <- b
    b <- temp
ENDPROCEDURE

FUNCTION Factorial(n : INTEGER) RETURNS INTEGER
    IF n <= 1 THEN
        RETURN 1
    ELSE
        RETURN n * Factorial(n - 1)
    ENDIF
ENDFUNCTION

DECLARE x : INTEGER
DECLARE y : INTEGER
x <- 10
y <- 20
CALL Swap(x, y)
OUTPUT "x = ", x, ", y = ", y
OUTPUT "5! = ", Factorial(5)
```

### Multi-way Selection (`CASE OF`)
```text
DECLARE code : INTEGER
code <- 2

CASE OF code
    1, 2:
        OUTPUT "Priority Level 1"
    3:
        OUTPUT "Priority Level 2"
    OTHERWISE:
        OUTPUT "Unknown Level"
ENDCASE
```

### Text File I/O
```text
DECLARE line : STRING

OPENFILE "data.txt" FOR WRITE
WRITEFILE "data.txt", "Item 1"
WRITEFILE "data.txt", "Item 2"
CLOSEFILE "data.txt"

OPENFILE "data.txt" FOR READ
WHILE NOT EOF("data.txt") DO
    READFILE "data.txt", line
    OUTPUT "Read: ", line
ENDWHILE
CLOSEFILE "data.txt"
```

## Architecture

```text
source.pseudo
     │
     ▼
  Lexer           (Token stream, source positions)
     │
     ▼
  Parser          (Recursive descent -> AST)
     │
     ▼
Semantic Analysis (Type checking, scope resolution, symbol tables)
     │
     ├──────────────────────────┐
     ▼                          ▼
Bytecode Compiler           C Code Generator
     │                          │
     ▼                          ▼
Pseudoc VM                  output.c (C99 source)
(Call frames, stack,        (Compiled with gcc/clang)
 references, file tables)
```

- **`src/lexer.*`**: Tokenizer with line/column tracking.
- **`src/parser.*`**: Recursive-descent parser producing AST nodes defined in `src/ast.h`.
- **`src/sema.*`**: Type-checking, scope validation (procedure/function/global), `BYREF` lvalue constraints, and record layout checks.
- **`src/bytecode.*`**: Opcode emitter, constant pool management, and bytecode disassembler.
- **`src/vm.*`**: Stack-based execution engine with activation frames, indirect reference targets for `BYREF`, and managed file handles.
- **`src/codegen.*`**: C emitter with memory-managed string tracking, integer overflow checks, and array boundary checks.
